## Deferred from: code review of 6-4-gagner-la-nuit (2026-11-24)

- **Première victoire : écouter `run_ended(VICTORY)`, pas `boss_defeated`** (story 6.7) : `Boss._on_death` émet `boss_defeated` sans savoir si la run est finie ni si ce boss est le plus profond (`Run` filtre : `_ended`, joueur mort, `floor_index`).
